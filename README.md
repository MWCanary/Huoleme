# 活了么 (Huoleme)

> 灵感来源于死了么（现在么在么）。此软件的设计、功能等所有内容都与死了么有些差别。  
> **主打纯本地离线运行，无任何云端服务器。**  
> 软件由 Gemini 开发，此前已有多个版本。

## 核心功能

1. **每日生存打卡与连续守护**
   - 首页支持一键每日确认打卡、实时显示今日状态、距离下次检测倒计时及连续打卡天数统计。
   - 支持设备摇一摇快捷打卡与通知栏“快速确认”操作。
2. **本地打卡记录与位置信息**
   - 使用本地 Room 数据库持久化存储每日打卡档案（日期、时间戳、定位经纬度信息）。
   - 自动记录打卡时的地理坐标（需授予位置权限），支持历史记录列表查看。
3. **定时提醒与后台守护**
   - 支持自定义每日提醒时间（默认 22:00），漏打卡时通过高优先级通知与间歇震动/提示音提醒。
   - 支持可选前台守护服务及开机自启恢复提醒调度。
4. **个人留言与个性化设置**
   - 支持保存个人生日、生前留言 / 紧急嘱托。
   - 支持多套主题风格（含自定义主题色、深色模式）、多语言（简体中文 / English）、全局字体大小调节及动画开关。
5. **纯本地数据备份与恢复**
   - 支持将全部打卡记录与常规偏好设置导出为本地 JSON 文件，也可随时从 JSON 文件导入恢复，所有数据均留在用户设备本地。

## 隐私与权限说明

本应用无任何云端服务器，不会向外部上传个人打卡记录、位置坐标或个人留言。声明的权限仅用于以下本地功能：

- **通知权限（`POST_NOTIFICATIONS`）**：在未按时打卡或后台守护异常终止时向用户发送本地提醒。
- **位置权限（`ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION`）**：仅在本地记录打卡时的经纬度坐标，不上传至任何服务器。
- **震动 / 精确闹钟 / 开机广播（`VIBRATE` / `SCHEDULE_EXACT_ALARM` / `RECEIVE_BOOT_COMPLETED`）**：保证每日提醒按时触发并在设备重启后恢复闹钟。
- **前台服务与电池优化豁免**：按需提升后台生存提醒的稳定性。

## 更新日志

### v1.3.7 Dev Gen 2 (versionCode 137)
- **定位显示修复**
  - 修复已授予位置权限时打卡记录仍显示“无位置”的问题：支持 `Fused` / `Network` / `GPS` 多定位源协同与回退，兼容仅授予大致位置（`ACCESS_COARSE_LOCATION`）的场景。
  - 修复刚启动或刚授权后立即打卡时异步定位尚未返回导致写入“无位置”的竞态问题：打卡后若定位正在获取中，坐标返回后会自动回填更新今日打卡记录；回到前台（`ON_RESUME`）及授权后亦会自动刷新并补全当日缺失位置。
  - 修复首次定位失败后被 60 秒冷却误锁以及重复请求互相取消的问题，改为共享进行中的定位请求。
- **后台内存占用与电量消耗优化**
  - 定位请求统一使用应用级上下文，增加单次并发去重、10 秒硬性超时限制、2 分钟缓存复用与 60 秒刷新冷却；后台通知快捷打卡仅读取系统缓存位置，不唤醒 GPS 射频。
  - 摇一摇加速度传感器在页面退至后台与销毁时主动注销监听并清理超时任务与静态回调。
  - 首页倒计时协程绑定 `STARTED` 生命周期并预计算目标时间戳，退入后台自动挂起；脉冲无限动画仅在未打卡且开启动画时运行。
  - 前台守护服务增加运行状态防重与异常捕获，移除冗余 `PendingIntent` 分配；提示音播放器改用线程锁与 `try/finally` 确保原生音频资源及时释放。
- **已知 Bug 修复**
  - 修复应用驻留后台跨零点后今日打卡状态与连续天数未刷新的问题。
  - 将 JSON 数据导出/导入解析及文件流读写迁至后台线程，导入后自动同步界面设置并重设闹钟。
  - 修复通知时间设置连续编辑保存竞态、遗嘱输入框同步及后台广播默认提醒时间不一致等问题。
